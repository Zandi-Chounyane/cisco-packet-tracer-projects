Cisco Packet Tracer University Projects:

This repository contains my university projects and lab simulations built in Cisco Packet Tracer. Each project covers practical network engineering and security concepts, such as subnetting, routing, firewall policies, VPNs, network segmentation, and threat analysis, designed to apply theory to realistic network scenarios.

Contents:
- .pkt simulation files and network topologies
- Router, switch, and firewall configuration notes
- Design breakdowns, security analyses, and verification steps

Tools & Focus Areas:
- Simulation Tool: Cisco Packet Tracer
- Core Topics: Subnetting, ACLs & NAT, Firewalls, IPsec VPNs, Network Segmentation, and Security Monitoring
